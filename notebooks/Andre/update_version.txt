# 3. SÓ ENTÃO cria a tag — aponta pra esse commit

git push origin v4.1.4
2. A tag dispara automaticamente o workflow GHCR

Você não precisa rodar workflow manual. O docker-publish-hpc.yml tem trigger on: push: tags: ['v*'], então git push origin v4.1.4 já faz tudo:

Builda a imagem com o source na revisão v4.1.4
Publica em ghcr.io/ritchielab/biofilter-hpc:4.1.4 + :latest
Acompanha em https://github.com/RitchieLab/biofilter/actions ou gh run watch.

3. PyPI publish (separado do GHCR)


# Verifica que o credentials está configurado
poetry config pypi-token.pypi  # ou: poetry config http-basic.pypi <user> <pass>

# Build + publish
poetry build
poetry publish
Se nunca rodou antes, vai precisar criar um API token em https://pypi.org/manage/account/token/ e configurar com poetry config pypi-token.pypi <token>.
